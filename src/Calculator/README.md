# Assignment 10 - Understanding .NET

This assignmnet contains a basic calculator application developed using a .NET class library to understand the fundamentals of `.NET` and `C#`.

## Menu Options

1. Add two integer
2. Subtract two integer
3. Multiply two integer
4. Divide two integer
5. Exit

## Add two integer

- Get two integer input from the user.
- Returns the sum of two integers.

## Subtract two integer

- Get two integer input from the user.
- Returns the difference between the two integers.

## Multiply two integer

- Get two integer input from the user.
- Returns the product of two integers.

## Divide two integer

- Get two integer input from the user.
- Returns the returns their quotient.
