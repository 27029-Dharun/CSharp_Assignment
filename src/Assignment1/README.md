# Assignment1: Contact Manager Console Application

A simple, menu‑driven **Contact Manager** that runs in the console.  
It allows you to **add, view, edit, and delete contacts** 

---

## Features

-  **Add Contact** — Save a new contact with name, phone, email, and notes.
-  **View Contacts** — View all saved contacts in a clean table format.
-  **Edit Contact** — Update any field (name, email, phone, notes) for an existing contact.
-  **Delete Contact** — Remove a contact by selecting its number.
-  **Search Contact** - Search Contact by entering Name
-  **Sort Contact** - Sort all the contact

## How to View and Use
Once you run the application, you’ll see the main menu in your terminal:

Contact Manager Application

Enter the number to Continue with an Operation
1. Add the contact
2. View the contact
3. Edit the contact
4. Delete the contact
5. Search contact By Name
6. Sort Contact
Type [exit] To Exit

You can navigate the app by typing the number of the action you want and pressing Enter.

### 1️. Add a Contact
Select 1 from the menu.

Enter the contact details when prompted:
Name — Dharun
Phone — must be 10 digits (e.g., 8248861963)
Email — must be in a valid format (e.g., dharun@example.com)
Notes — any extra info (optional)
If all inputs are valid, you’ll see:

Contact added successfully.

### 2. Display All the contact
Select 2 from the menu.
The app will display all saved contacts in a list:

### 3. Edit Contact
Select 3 from the menu.
Will display all the Contacts
Choose the contact to edit.

You’ll see the current details and a menu:

1. Edit Name
2. Edit Email
3. Edit Phone
4. Edit Notes
Choose the field you want to change and enter the new value.
The app will confirm:

Contact updated successfully.

### 4. Search a Contact
Select 4 from the menu.
Enter the Name to Search
The application will print all the matched contactes with the name

### 5. Delete a Contact
Select 5 from the menu.
The app will show all contacts with their Serial Number.
Type the Serial Number of the contact you want to delete.
If found, the app will confirm:

Contact deleted successfully.

### 6. Sort a Contact
Select 6 from the menu.
All the contacts will be sorted and Displayed

### Exit the Application
Type "exit" to exit the Application
